# ทันควัน DISPATCH

เว็บไซต์จำลองบริการส่งพัสดุ (โปรเจกต์การเรียนวิชา Basic Website Creation)

## โครงสร้างโฟลเดอร์
```
tankwan-dispatch/
├─ index.html
├─ tankwan-*.html      (แต่ละหน้าบริการ)
├─ css/
│  └─ tankwan-core.css
├─ js/
│  ├─ tankwan-utils.js
│  ├─ tankwan-nav.js
│  ├─ tankwan-audio.js        (เพลงพื้นหลัง — ดูหัวข้อด้านล่าง)
│  ├─ tankwan-location-picker.js
│  └─ flash-express-utils.js  (ไฟล์อ้างอิงสูตรคำนวณ ไม่ได้ถูกเรียกใช้จริง)
└─ assets/
   └─ audio/
      └─ bgm.mp3               (เพลงพื้นหลัง)
```

## เพลงพื้นหลัง (Background Music)
ทุกหน้าจะโหลด `js/tankwan-audio.js` ซึ่งเล่นไฟล์ `assets/audio/bgm.mp3` วนซ้ำอัตโนมัติ พร้อมปุ่มลอยมุมขวาล่างสำหรับเปิด/ปิดเสียง
- เพราะเว็บนี้เป็นเว็บหลายหน้า (ไม่ใช่ SPA) การเปลี่ยนหน้าจะโหลดหน้าใหม่ทุกครั้ง เพลงจึง **ไม่สามารถเล่นต่อแบบไม่สะดุดจริงๆ ได้** แต่สคริปต์จะจำตำแหน่งเวลาเพลงและสถานะเปิด/ปิดเสียงไว้ใน `localStorage` แล้วคำนวณให้เพลงเล่นต่อจากจุดที่ควรจะอยู่ (เหมือนเล่นต่อเนื่อง)
- เบราว์เซอร์ส่วนใหญ่ (Chrome, Safari) จะ**บล็อกการเล่นเสียงอัตโนมัติ**จนกว่าผู้ใช้จะคลิก/แตะหน้าเว็บก่อนอย่างน้อย 1 ครั้ง — สคริปต์จัดการเรื่องนี้ให้แล้ว (เริ่มเล่นแบบปิดเสียงไปก่อน แล้วเปิดเสียงอัตโนมัติทันทีที่มีการคลิกครั้งแรก)
- ไฟล์เพลงที่ใช้อยู่ตอนนี้คือเพลงประกอบเกม *Stardew Valley* ("Calico Desert" โดย Lewie Umney) **ซึ่งมีลิขสิทธิ์เป็นของผู้แต่งเพลง** เหมาะสำหรับใช้ส่งงาน/เดโมในห้องเรียนเท่านั้น หากจะ deploy ขึ้น GitHub Pages แบบ public จริงจัง แนะนำให้เปลี่ยนไปใช้เพลงที่ไม่มีลิขสิทธิ์ (royalty-free) แทน เพื่อเลี่ยงปัญหาลิขสิทธิ์

## รันดูบนเครื่องตัวเอง (VS Code)
1. เปิดโฟลเดอร์นี้ทั้งโฟลเดอร์ใน VS Code (File → Open Folder)
2. ติดตั้งส่วนขยาย **Live Server** (โดย Ritwick Dey) จาก Extensions
3. คลิกขวาที่ `index.html` → **Open with Live Server**
4. เบราว์เซอร์จะเปิดที่ `http://127.0.0.1:5500` โดยอัตโนมัติ

## ขึ้น GitHub + เปิดเป็นเว็บไซต์ (GitHub Pages)
```bash
git init
git add .
git commit -m "Initial commit: ทันควัน DISPATCH"
git branch -M main
git remote add origin https://github.com/<username>/<repo-name>.git
git push -u origin main
```
จากนั้นที่ repo บน GitHub → Settings → Pages → Branch เลือก `main` / โฟลเดอร์ `/root` → Save
รอ 1-2 นาที เว็บไซต์จะออนไลน์ที่ `https://<username>.github.io/<repo-name>/`

## แผนที่ (Leaflet + OpenStreetMap)
หน้าจองส่งพัสดุ (`tankwan-booking.html`) เปลี่ยนจาก Google Maps มาใช้ **Leaflet + OpenStreetMap** แทนแล้ว — ใช้งานได้ทันทีโดย**ไม่ต้องขอ API Key** ใดๆ
- พิมพ์ที่อยู่ในช่องแล้วกด **Enter** เพื่อค้นหาตำแหน่งบนแผนที่ (ผ่านบริการค้นหาของ OpenStreetMap ที่เรียกว่า Nominatim)
- คลิกหรือลากหมุดบนแผนที่ได้โดยตรง ระบบจะค้นชื่อที่อยู่ให้อัตโนมัติ (reverse geocoding)
- ถ้าอินเทอร์เน็ตหลุดหรือโหลดแผนที่ไม่สำเร็จ จะขึ้นข้อความสำรองให้กรอกที่อยู่เป็นตัวอักษรแทนโดยอัตโนมัติ
- Nominatim เป็นบริการฟรีของอาสาสมัคร OpenStreetMap มีข้อกำหนดว่าไม่ควรยิงคำขอถี่เกินไป (โค้ดนี้ค้นหาเฉพาะตอนกด Enter เท่านั้น ไม่ค้นหาทุกตัวอักษรที่พิมพ์) เหมาะกับโปรเจกต์เรียน/เดโมขนาดนี้ ถ้าจะใช้งานจริงจังปริมาณมากควรพิจารณาใช้บริการ geocoding อื่นที่รองรับปริมาณการใช้งานสูงกว่า
